About the Project

The Online Travel Package Booking Management System is a beginner-friendly web application for maintaining travel packages, customer information and booking records.

Technologies Used

  • HTML and CSS for the website pages
  • JavaScript for browser interactions
  • Node.js and Express.js for the backend
  • MySQL for storing project records
  • MySQL Workbench for graphical database management

Main Features

  • Add, view, update and delete travel packages
  • Add, view, update and delete customer details
  • Add, view, update and delete booking records
  • View all three database tables on the home page

Note: This is an educational mini project. It does not process real payments or verify travel availability.
